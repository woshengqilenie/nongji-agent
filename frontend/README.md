# 前端三端页面说明

前端现在改成了三端结构，直接由后端静态挂载：

- `/ui`：平台总览入口
- `/ui/rent`：租赁端
- `/ui/machine`：农机端
- `/ui/supervisor`：主管端
- `/ui/atlas`：全域地图
- `/ui-v2`：麦浪网格风新版入口

## 页面定位

### 租赁端

- 左侧：服务品类 + 一句话填单
- 中间：农机服务卡片列表
- 右侧：快速下单 + 我的订单 + 订单轨迹

### 农机端

- 左侧：机主切换 + 任务分组
- 中间：任务详情与时间轴
- 右侧：接单、拒单、改约、出发、开工、完工、故障上报
- GPS 作业核算：开始作业后模拟轨迹、覆盖面积和实际亩数

### 主管端

- 顶部：平台指标
- 左侧：待派单 / 待响应 / 异常 / 履约中订单池
- 中间：派单候选、天气上下文、异常动作
- 右侧：区域热力、机主服务分、最近动态

### 全域地图

- 左侧：空间数据指标、筛选器、图层开关、选中详情
- 右侧：高德地图全屏总览，统一展示农机、地块、覆盖圈、调度线路和天气预警

## 主要文件

- `index.html`：平台总览入口
- `rent/index.html`：租赁端页面
- `machine/index.html`：农机端页面
- `supervisor/index.html`：主管端页面
- `atlas/index.html`：全域地图页面
- `styles.css`：三端共用样式
- `shared.js`：共用请求与渲染工具
- `rent.js`：租赁端逻辑
- `machine.js`：农机端逻辑
- `supervisor.js`：主管端逻辑
- `atlas.js`：全域地图逻辑

## 运行方式

```bash
cd backend
python scripts/seed_from_mock.py
uvicorn app.main:app --reload --port 8000
```

然后打开 `http://127.0.0.1:8000/ui` 即可。  
建议演示顺序：

1. 租赁端创建并支付订单
2. 主管端生成派单建议并确认
3. 农机端接单、出发、作业
4. 农机端点击开始作业，演示 GPS 轨迹和作业面积核算
5. 回到主管端演示天气或故障异常
